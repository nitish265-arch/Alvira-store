# ALVIRA Store

Static, mobile-first ALVIRA jewellery storefront.

## Included
- Raksha Bandhan campaign
- Real sale prices supplied for the three main offers
- Product filtering and search
- Product quick-view modal
- Cart with quantity controls
- Order summary copy flow
- Individual product artwork cropped from the supplied ALVIRA contact sheet

## Pricing
- ₹3,800 → ₹1,699 = 55% off (rounded)
- ₹3,400 → ₹1,399 = 59% off (rounded)
- ₹1,000 → ₹499 = 50% off

The earlier 42% / 40% discount labels do not mathematically match those MRP/sale prices, so the site uses the actual discounts.

## Deploy
Upload/push the project to the same Vercel project. No build step is required; it is plain HTML/CSS/JS.
