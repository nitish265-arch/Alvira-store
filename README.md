# ALVIRA Store — Starter

This is the first static homepage prototype for ALVIRA.

## Run it
Open `index.html` in a browser, or serve the folder with any simple local web server.

## Current
- Responsive premium jewellery homepage
- Mobile navigation
- Search/filter
- Product cards
- Cart drawer
- Hero, categories, collection, gallery and reviews
- Uses the supplied ALVIRA image as temporary product/gallery artwork
